# Stack & Queue worksheets

ใบงานภาษาไทยสำหรับวิชา Data Structure ชั้นปี 2 แยก 2 กิจกรรม กิจกรรมละ 90 นาที ใช้ ANSI C และอาร์เรย์ โดยไม่ใช้ pointer

เปิด `index.html` ได้โดยตรง หรือวางโฟลเดอร์ `stack-queue` ในแหล่งเผยแพร่ GitHub Pages เดิม แล้วเข้าพาธ `/stack-queue/` ไม่มี build และไม่มี dependency ภายนอก

## ไฟล์
- `stack.html`: ใบงาน Stack
- `queue.html`: ใบงาน Circular Queue (ใช้ count แยกเต็ม/ว่าง ใช้ได้ครบ 5 ช่อง)
- `worksheet.js`: จำลองโครงสร้าง บันทึกคำตอบใน localStorage และส่งออก JSON
- `stack_starter.c`, `queue_starter.c`: โค้ดเริ่มต้นที่มี TODO สำหรับนักศึกษา ไม่ใช่เฉลย

## เผยแพร่
หลัง merge ให้เลือก Settings → Pages และเลือก branch/folder ที่ต้องการเผยแพร่ตามสิทธิและแผน GitHub ของบัญชี Repository นี้เป็น private ณ เวลาจัดทำ จึงต้องตรวจสิทธิ Pages ก่อนเผยแพร่ ชุดงานนี้ไม่เปลี่ยน visibility ของ repository และไม่ได้เปิด Pages ให้อัตโนมัติ

หากเผยแพร่จาก root ให้เข้าพาธ `stack-queue/index.html` ใต้ URL Pages ที่ GitHub แจ้ง ไม่จำเป็นต้องแทนที่ README หรือไฟล์เดิม

## การใช้งานในชั้นเรียน
ทำนายก่อนใช้ตัวจำลอง จากนั้นเติมโค้ดและคอมไพล์ด้วย `gcc -std=c90 -Wall -Wextra -pedantic` ตรวจกรณีว่าง เต็ม Peek และการวนรอบ ส่งไฟล์ C ผลทดสอบ และคำตอบ JSON/PDF ผ่านช่องทางที่ผู้สอนกำหนด คะแนนต่อใบงาน 20 คะแนน

การติ๊กขั้นตอนเป็นการรายงานความคืบหน้า ไม่ใช่การตรวจคำตอบ ตัวจำลองไม่ได้ตรวจโปรแกรม C ไม่มีบัญชีผู้ใช้ ระบบรับงาน หรือฐานข้อมูล คำตอบบันทึกเฉพาะเบราว์เซอร์/อุปกรณ์นี้ การล้างข้อมูลเบราว์เซอร์จะลบคำตอบ ควรดาวน์โหลดก่อนปิดการใช้งานบนเครื่องส่วนรวม
