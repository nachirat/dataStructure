Circular Queue — First In, First Out

เรียนรู้ด้วยการทำนาย ทดลอง เขียนโปรแกรม และตรวจสอบผลด้วยหลักฐาน

สิ่งที่ใช้: คอมพิวเตอร์ และ C compiler เช่น GCC · พื้นฐาน: อาร์เรย์ ฟังก์ชัน เงื่อนไข และลูป

ผลลัพธ์การเรียนรู้: อธิบายลำดับข้อมูล ติดตามดัชนี พัฒนาโครงสร้างด้วยอาร์เรย์ และจัดการ Overflow/Underflow ได้

ใบงานสรุป

คลิกหัวข้อเพื่อดูขั้นตอน ทำเครื่องหมายเมื่อเสร็จ และบันทึกคำตอบ คำตอบเก็บในเบราว์เซอร์ของเครื่องนี้เท่านั้น ไม่ส่งให้อาจารย์อัตโนมัติ

2.1 ทำนายก่อนทดลอง · 10 นาที

เปรียบเทียบกองจานกับแถวรอรับบริการ เลือกว่าสถานการณ์ใดใช้ LIFO และสถานการณ์ใดใช้ FIFO พร้อมอธิบายเหตุผล

เริ่ม front = 0, rear = -1, count = 0; front ชี้สมาชิกที่จะนำออก และ rear ชี้สมาชิกล่าสุด; ว่างเมื่อ count == 0; เต็มเมื่อ count == CAPACITY; เลื่อนดัชนีด้วย (index+1)%CAPACITY โดยไม่ย้ายข้อมูล เมื่อว่างค่าดัชนียังคงอยู่และต้องตรวจ count ก่อนอ่าน

2.4 ทดสอบขอบเขต · 20 นาที

  1. เรียกนำออกและ Peek ขณะว่าง สถานะต้องไม่เปลี่ยน
  2. เพิ่มข้อมูลให้ครบ 5 ค่า แล้วเพิ่มครั้งที่ 6 ต้องแจ้ง Overflow
  3. Peek ซ้ำสองครั้ง จำนวนสมาชิกต้องคงเดิม
  4. นำข้อมูลออกจนหมดแล้วเพิ่มใหม่ โครงสร้างต้องกลับมาใช้งานได้
  5. นำออก 2 ค่าจากคิวเต็ม แล้วเพิ่ม 2 ค่า ต้องใช้ช่องที่ว่างจากการวนรอบได้ โดยลำดับบริการยังเป็น FIFO
