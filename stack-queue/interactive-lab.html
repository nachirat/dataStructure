NOTES FOR STUDENTS
ทำความเข้าใจโครงสร้าง
Stack: Last In, First Out
เหมือนกองจาน เพิ่มและนำออกด้านบนเดียวกัน ตัวแปร top ชี้สมาชิกล่าสุด เริ่มที่ −1 เมื่อว่าง Push เลื่อน top แล้วเก็บค่า ส่วน Pop อ่านค่าก่อนลด top
empty: top == -1
full: top == CAPACITY - 1
Circular Queue: First In, First Out
เหมือนแถวรอรับบริการ front ชี้สมาชิกถัดไปที่จะนำออก rear ชี้สมาชิกล่าสุด count ระบุจำนวนสมาชิก ดัชนีวนด้วย modulo จึงใช้ช่องที่ว่างได้โดยไม่ย้ายข้อมูล
empty: count == 0
full: count == CAPACITY
next = (index + 1) % CAPACITY
ทุกคำสั่งมาตรฐานในตัวอย่างนี้เป็น O(1) ส่วนพื้นที่ของอาร์เรย์ความจุ N เป็น O(N) การวาดภาพและสร้างตารางในหน้าเว็บเป็นงานแสดงผลแยกจากอัลกอริทึมนี้
สำหรับคิวว่าง front/rear อาจยังมีค่าดัชนีเก่าอยู่ ต้องตรวจ count ก่อนอ่านข้อมูลเสมอ ใช้ count แยกสถานะเต็มและว่าง จึงเก็บข้อมูลได้ครบ CAPACITY ช่อง

ตรวจความเข้าใจด้วยตนเอง
1. เพิ่ม 10, 20, 30 แล้วนำออกหนึ่งครั้ง: Stack กับ Queue ต่างกันอย่างไร?
Stack นำ 30 ออก เพราะเข้าล่าสุด ส่วน Queue นำ 10 ออก เพราะเข้าก่อน
2. ถ้า Queue ความจุ 5 เต็ม แล้วนำออก 2 ค่า จะเพิ่มใหม่ได้กี่ค่า?
เพิ่มได้ 2 ค่า เพราะ count เหลือ 3 ใช้ modulo เลื่อน rear กลับไปช่องว่าง และยังรักษาลำดับ FIFO
3. Peek เปลี่ยนจำนวนสมาชิกหรือดัชนีหรือไม่?
ไม่เปลี่ยน เป็นการอ่านข้อมูลถัดไปที่จะนำออกเท่านั้น และต้องตรวจว่างก่อนอ่าน
4. ทำไมการนำออกเมื่อว่างต้องไม่อ่านอาร์เรย์?
ไม่มีสมาชิกที่ใช้งานอยู่ สำหรับ Stack top อาจเป็น −1 ซึ่งอยู่นอกขอบเขตอาร์เรย์ ส่วน Queue อาจอ่านค่าค้างที่ไม่ใช่สมาชิกปัจจุบัน
5. ทำไมจึงบอกว่าคำสั่งเหล่านี้เป็น O(1)?
แต่ละคำสั่งตรวจเงื่อนไข อ่าน/เขียนหนึ่งค่า และปรับตัวแปรจำนวนคงที่ ไม่เลื่อนสมาชิกทุกตัว
